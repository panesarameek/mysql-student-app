# mysql-student-app
For this project, I built a desktop application using Python to automate how student enrollment data is collected and managed. I wanted to create something practical that replaces manual paperwork with a clean, digital form, making the registration process a lot faster and less prone to mistakes.

The main feature of the app is how it handles data storage. Whenever someone fills out and submits the student form, the backend Python script immediately saves that information in two different places at the same time: a MySQL database and an Excel spreadsheet. I integrated a relational MySQL database to ensure that the student records are stored securely, organized properly, and easy to query for long-term use. At the same time, I wrote code to automatically export the data into an Excel sheet. This makes it super easy for school administrators to open up the file right away, do quick offline analysis, or share student lists without needing to know how to use a database.
